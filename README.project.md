# Мини-визуальная новелла

Проект запускает интерактивную веб-новеллу на основе сценария и изображений из этой папки.

## Что внутри

- `index.html` — страница новеллы.
- `css/styles.css` — оформление, адаптив и анимации.
- `js/app.js` — движок воспроизведения (реплики, тайпинг, выборы, переходы, очки).
- `data/assets.js` — маппинг всех фонов и персонажей на файлы изображений.
- `data/scenario.js` — сценарий в формате данных (узлы, события, ветвления).
- `data/scenario-source.txt` — извлеченный текст сценария из `.docx`.
- `tools/extract_docx_text.ps1` — скрипт повторного извлечения текста из `игра МП ф..docx`.
- `tools/remove_sprite_bg.py` — скрипт вырезки белого фона у `янсели*.png` (с бэкапом оригиналов в `_backup_sprites_original/`).

## Запуск

### Вариант 1: открыть напрямую

Просто откройте `index.html` в браузере.

### Вариант 2: через локальный сервер (рекомендуется)

```powershell
cd E:\informatica\vnm
python -m http.server 8080
```

Далее откройте: `http://localhost:8080`

## Управление

- Клик в любом месте сцены — следующий шаг.
- `Enter` или `Space` — следующий шаг.
- Во время печати текста повторный клик/клавиша мгновенно допечатывает текущую реплику.
- Следующий клик переводит к следующему событию.
